1. PROJECT OVERVIEW & PURPOSE
===============================================================================

WHAT WE BUILT:
We created a research-grade validation system to test the accuracy of gaze 
event classification algorithms. The system validates how well our I-DT 
(Dispersion-Threshold) algorithm can correctly identify different types of 
eye movements.

WHY WE BUILT IT:
In eye-tracking research, you need to know if your classification algorithm 
is working correctly. Without validation, you can't trust your results. 
Our system creates controlled experiments where we know exactly what type 
of eye movement a person should be doing (ground truth), then compares that 
to what our algorithm detects.

THE CORE PROBLEM WE SOLVED:
How do you scientifically validate that an eye-tracking system correctly 
classifies fixations, saccades, and smooth pursuit movements?

3. EXPERIMENTAL PROTOCOL DESIGN
===============================================================================

WHY WE CHOSE THIS APPROACH:
Our experimental protocol follows established eye-tracking research standards 
from recent literature (2023-2025). We implemented a controlled stimulus 
presentation methodology that creates clear ground truth conditions.

THE THREE TRIAL TYPES:

1. FIXATION TRIALS:
   STIMULUS: Red dot with white crosshairs in screen center
   INSTRUCTION: "Look steadily at the RED DOT - keep your gaze fixed!"
   GROUND TRUTH: User should maintain stable gaze on one point
   EXPECTED PATTERN: Low dispersion, low velocity, sustained duration
   
   WHY THIS WORKS: Fixations are characterized by minimal eye movement.
   By giving users a clear, visible target and explicit instructions to 
   "stare at it," we create ideal conditions for fixation detection.

2. SACCADE TRIALS:
   STIMULUS: Blue dot (left) and green dot (right) with yellow arrow
   INSTRUCTION: "Quickly move your eyes from BLUE dot to GREEN dot!"
   GROUND TRUTH: User should make rapid ballistic eye movement
   EXPECTED PATTERN: High velocity, large dispersion, short duration
   
   WHY THIS WORKS: Saccades are rapid eye jumps between fixation points.
   By placing targets at specific distances and instructing quick movement,
   we force the eye to make the characteristic ballistic motion pattern.

3. SMOOTH PURSUIT TRIALS:
   STIMULUS: Moving yellow dot along horizontal dotted path
   INSTRUCTION: "Smoothly follow the YELLOW DOT as it moves!"
   GROUND TRUTH: User should track moving target continuously
   EXPECTED PATTERN: Moderate velocity, high dispersion, smooth tracking
   
   WHY THIS WORKS: Pursuit movements occur when tracking moving objects.
   The animated dot creates a predictable motion pattern that requires
   continuous smooth eye movement to follow accurately.

EXPERIMENTAL CONTROLS:
- Trial order randomization to prevent order effects
- Consistent 3-second trial duration for comparable data
- Clear visual instructions for each trial type
- Immediate visual feedback through stimulus presentation
- Rest periods between trials to prevent fatigue

5. I-DT CLASSIFICATION ALGORITHM
===============================================================================

ALGORITHM OVERVIEW:
We implement the I-DT (Dispersion-Threshold) algorithm, which is a standard 
method in eye-tracking research for classifying gaze events based on spatial 
dispersion and temporal velocity characteristics.

THE CLASSIFICATION LOGIC:

STEP 1: DATA COLLECTION
- Collect gaze events during 3-second trial windows
- Filter events by timestamp to ensure trial-specific data
- Handle both pixel coordinates and normalized coordinates
- Account for missing or invalid data points

STEP 2: FEATURE EXTRACTION
Two primary metrics are calculated:

DISPERSION CALCULATION:
```
dispersion = sqrt((max_x - min_x)² + (max_y - min_y)²)
```
This measures how spread out the gaze points are spatially.

VELOCITY CALCULATION:
```
For each consecutive pair of points:
distance = sqrt((x2-x1)² + (y2-y1)²)
velocity = distance / time_difference
average_velocity = mean(all_velocities)
```
This measures how fast the eye is moving.

STEP 3: CLASSIFICATION RULES
Based on research literature, we use these thresholds:

FIXATION DETECTION:
- Dispersion < 50 pixels AND
- Average velocity < 100 pixels/second AND
- Duration > 100ms
- Confidence: 0.85

SACCADE DETECTION:
- Average velocity > 300 pixels/second OR
- Dispersion > 200 pixels
- Confidence: 0.80

PURSUIT DETECTION:
- Dispersion > 50 pixels AND
- 50 < Average velocity < 200 pixels/second AND
- Duration > 500ms
- Confidence: 0.75

UNKNOWN CLASSIFICATION:
- Any pattern not matching the above criteria
- Confidence: 0.30-0.50

WHY THESE THRESHOLDS:
- Based on established eye movement research parameters
- Tuned for consumer-grade eye tracker precision
- Account for individual differences in eye movement patterns
- Provide reasonable separation between movement types

7. VALIDATION METRICS & ANALYSIS
===============================================================================

GROUND TRUTH COMPARISON:
The core validation principle is comparing known ground truth (what the user
was instructed to do) against algorithm predictions (what our classifier
detected).

ACCURACY METRICS CALCULATED:

1. OVERALL ACCURACY:
   correct_classifications / total_trials * 100
   
   This gives the percentage of trials where the algorithm correctly
   identified the intended eye movement type.

2. PER-CLASS ACCURACY:
   For each movement type (fixation, saccade, pursuit):
   - Total trials of this type
   - Correct classifications for this type
   - Class-specific accuracy percentage
   
   This reveals which movement types are hardest to classify.

3. CONFUSION MATRIX:
   Shows what the algorithm predicts for each true movement type:
   - True Fixation → Predicted: Fixation, Saccade, Pursuit, Unknown
   - True Saccade → Predicted: Fixation, Saccade, Pursuit, Unknown  
   - True Pursuit → Predicted: Fixation, Saccade, Pursuit, Unknown
   
   This reveals systematic classification errors and biases.

4. CONFIDENCE ANALYSIS:
   - Average confidence scores for correct classifications
   - Average confidence scores for incorrect classifications
   - Confidence distribution patterns
   
   This helps tune algorithm thresholds and assess reliability.

STATISTICAL SIGNIFICANCE:
- Multiple trials per type reduce random variation effects
- Randomized trial order prevents systematic biases
- Participant-specific results allow individual difference analysis
- Session-to-session comparison enables reliability assessment
